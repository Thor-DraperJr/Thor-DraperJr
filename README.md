# Thor Draper Jr

I am a Senior Security Solutions Engineer at Microsoft working with healthcare and life sciences organizations. My work centers on Microsoft Sentinel, Defender XDR, Azure security, and the practical adoption of AI in security operations.

My path into cybersecurity included the National Guard, sales, sales leadership, entrepreneurship, and a SANS Technology Institute degree in Applied Cybersecurity. That background still shapes how I build: start with the person and the operational problem, then make the technology useful, explainable, and safe to run.
